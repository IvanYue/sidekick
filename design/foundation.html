Sidekick 设计系统

这一份是 Sidekick 桌面版 UI 重构的单一真值层。所有颜色、字号、间距、圆角、动效都定义在 design/tokens.css 的 CSS 变量里；界面稿 index.html 与未来的 Flutter theme.dart 都从这一层取值，不允许各自硬编码。

01

工具感优先

这是开发者的桌面工具，不是消费级应用。信息密度优先，动效克制，语义色只用于状态而非装饰。

02

层级靠留白与字重

不用阴影堆叠。面板靠 1px 分隔线与背景明度差分层，标题靠字号 / 字重拉开，避免视觉噪声。

03

状态永远有出口

空态、错误态、加载态都给出「下一步该做什么」，而不是只描述失败原因。反馈 3.5s 内自动消失。

04

双主题同构

深色是暖中性石墨底，浅色是暖白纸底。两者共用同一套语义变量名与对比度目标，不是简单反色。

一、色彩

底色采用暖中性（带一点红调的灰），而不是纯冷灰 —— 长时间盯屏时暖底更松弛，也让三色强调更协调。 强调色不取品牌蓝紫，而是陶土橙；辅以灰蓝（信息 / 全局版本）与橄榄绿 （OHOS / 成功）。

语义强调色

语义色只用于表达状态：accent 是「当前选中 / 需要你做主操作」， info 是「这条信息值得注意但不是错误」，ok 是「已就绪 / 成功」， warn 是「有更新 / 有风险但不阻塞」，danger 才是真正的错误。

二、字体与字阶

三款字体各司其职：Poppins 做标题与品牌（几何感强，字面识别度高）， IBM Plex Sans 做正文（中文回退 PingFang SC，工具感强）， JetBrains Mono 承载一切技术值（版本号、SHA、路径、Hash）。

三、间距与尺寸

4px 基准栅格。桌面端密度中偏高：列表行 64px（双行）/ 44px（紧凑单行）， 按钮 28px 高，输入框 28px，触摸目标通过图标按钮 24px + 间距保证 ≥ 32px 可点区。

五、动效与可访问性

即时反馈 120ms · ease-out hover 底色、按钮按下
常规转场 180ms · cubic-bezier(.32,.72,0,1) 页面切换、抽屉开合、chip 变化
强调转场 280ms · cubic-bezier(.32,.72,0,1) 模态进出、抽屉滑入
  • 所有过渡使用同一条 easing 曲线，避免每个组件各调各的。
  • 只动 transform 与 opacity；宽度 / 高度动画一律不用。
  • prefers-reduced-motion: reduce 时全部降到 0.01ms。
  • 所有图标按钮必须带 aria-label 或 tooltip；纯图标不可裸奔。
  • 焦点环保留（:focus-visible），不因「更干净」而移除。
  • 状态不只靠颜色表达 —— 徽章均带文字，更新状态同时给出图标 + 文案。

六、落到 Flutter 的映射

重构时按下面三步走，不动任何业务逻辑，只替换渲染层：

步骤 文件 内容
1 · 令牌 lib/src/design/tokens.dart 把 tokens.css 的 CSS 变量翻译成 Dart 常量（颜色、字阶、间距、圆角、动效）
2 · 主题 lib/src/design/theme.dart 基于 tokens 构造 2 套 ThemeData（深 / 浅），替换现有 4 套主题
3 · 组件 lib/src/design/kit/ 按钮 / 徽章 / 瓦片 / 列表项 / 面板 / 字段 / 开关 / 分段控件

现有 lib/src/theme.dart 的 4 套主题（darkPurple / darkBlue / dark / light） 会被收敛为深浅两套 —— 用户主题切换从「四选一」改为「深 / 浅」，这是本次重构中唯一的行为变更。
